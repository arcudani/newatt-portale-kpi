# Controllo BP Migliora

Dashboard di controllo del Business Plan 2026-2030 di Migliora, sul modello DeD **3-30-300**:
3 secondi per la Direzione (Cruscotto), 30 per i responsabili di funzione (Economico, Commerciale
Agenti, VAS, Operations), 300 per chi lavora sui driver (Scostamenti, FTE, Versioni, Catalogo KPI).

App Streamlit di Bros Consulenza, separata dall'ERP, con utenti propri (Bros e NeWatt) e dati su
Supabase. Avvio locale, test e architettura: [CLAUDE.md](CLAUDE.md). Pubblicazione: [DEPLOY.md](DEPLOY.md).
